# 🛒 E-commerce Customer Analysis using Python

## 📖 Project Overview
This project focuses on analyzing an e-commerce dataset to understand customer behavior, purchasing patterns, and revenue distribution. The analysis aims to uncover actionable insights that can help businesses improve customer retention and maximize revenue.

---

## 🎯 Objectives
- Analyze customer purchase behavior
- Identify repeat vs one-time customers
- Perform customer segmentation (RFM Analysis)
- Understand revenue contribution patterns
- Discover trends in orders and payments

---

## 📂 Dataset Description
The dataset contains multiple tables related to:
- Customers
- Orders
- Order items
- Payments

These datasets were merged and analyzed to generate meaningful insights.

---

## ⚙️ Project Workflow (Step-by-Step)

### 1. Data Collection
- Imported multiple CSV datasets
- Loaded data using Pandas

### 2. Data Cleaning
- Handled missing values
- Converted date columns into datetime format
- Removed duplicates and irrelevant columns

### 3. Data Preparation
- Merged multiple tables into a single dataset
- Created new features for analysis

### 4. Exploratory Data Analysis (EDA)
- Analyzed order trends over time
- Checked distribution of customers and orders
- Visualized sales patterns

### 5. Customer Analysis (RFM)
- **Recency** → Days since last purchase  
- **Frequency** → Number of purchases  
- **Monetary** → Total spending  

- Segmented customers into categories:
  - High-value customers
  - One-time buyers
  - Potential loyal customers

### 6. Visualization
- Used Matplotlib & Seaborn
- Created:
  - Sales trend graphs
  - Customer distribution charts
  - RFM segmentation visuals

---

## 📊 Key Insights

- A large portion of customers are **one-time buyers**, indicating low retention
- A small segment contributes to **high revenue (high-value customers)**
- Customer purchasing behavior is **highly uneven**
- Opportunities exist to improve:
  - Customer retention
  - Repeat purchases
  - Targeted marketing
